# This is an unofficial fork

This is LordLundin's personal fork of [MSFS Blind Assist](https://github.com/oasis1701/msfs-blind-assist). It is not the official app. It is not made, endorsed, reviewed or supported by the MSFS Blind Assist developers, and nothing in it speaks for them.

## Why it exists

I build it for my own use, and anyone curious is welcome to try my changes. Each build is the official app's newest code, plus some pull requests still waiting for review in the official project (among them the COWS DA40), plus my own changes. That extra code has had less testing than an official release.

Bug fixes I make are offered to the official project as pull requests.

## Reporting problems

- Do not report a problem you found in this fork to the MSFS Blind Assist developers.
- First try the same thing in the [official release](https://github.com/oasis1701/msfs-blind-assist/releases/latest). If it happens there too, it is theirs to look at: report it to them as found in the official release.
- If it happens only in this fork, report it here, in [this fork's Issues](https://github.com/LordLundin/msfs-blind-assist/issues).

## Donations

If you want to support the app, donate to the original developers: [Ko-fi](https://ko-fi.com/oasis1701). This fork takes no donations.

## Updates

This build looks for updates in this fork, not in the official project. To go back to the official app, close MSFS Blind Assist, download MSFSBA.zip from the [official releases](https://github.com/oasis1701/msfs-blind-assist/releases/latest), and extract it over your installation folder. From then on it updates from the official project again. Settings that only this fork has are dropped the next time the official app saves its settings.
